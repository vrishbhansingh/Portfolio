# Vrishbhan Singh — Portfolio

Personal portfolio of a full stack developer (React.js and Laravel) who builds multi-tenant HRMS, CRM and ERP products.

Built with Next.js 16, Tailwind CSS v4, Motion and Lenis.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Edit content

All text, projects, experience and links live in `src/data/profile.ts`.
Product screenshots are in `public/work/`.

## Contact form (SMTP)

Copy `.env.example` to `.env.local` and fill in your SMTP details, then restart the dev server.
For Gmail, use an App Password.

## Build

```bash
npm run build
npm start
```
